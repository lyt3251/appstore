BizKeigo – Privacy Policy

Last updated: 2026-05-21

要点

本アプリはユーザーの入力テキストを外部サーバーに送信しません。ログイン・広告SDKは使用しません。機能改善のため、Firebase Analytics（Google）を用いてボタン操作などの匿名利用統計を収集しています。収集するのは操作イベントのみで、入力テキストや個人情報は含まれません。

1. 収集する情報

本アプリ（失礼チェック / BizKeigo）は以下の情報のみを収集します。

  • 端末内に保存（外部送信なし）： アプリ設定（言語・テーマ・オンボーディング完了状態）、ユーザーが作成したテンプレート・常用フレーズ・チェック履歴
  • Firebase Analytics に送信する匿名データ：
    • ボトムナビゲーションのタブ切り替え操作
    • 「文章を分析」「テンプレート生成」「コピー」「保存」などのボタン操作
    • 設定変更（言語・外観の切り替え、データ削除の実行）

上記の匿名イベントには、入力テキスト・氏名・メールアドレス等の個人を識別できる情報は一切含まれません。

2. テキストの処理

入力されたビジネス日本語の文章は、標準では端末内のみで解析・スコアリングされます。文章は外部AIサービス・翻訳API・その他のサーバーに送信されません。

3. クリップボードの利用

アプリはユーザーが「貼り付け」または「コピー」操作を明示的に行った場合にのみクリップボードにアクセスします。クリップボードの内容を自動取得したり外部に送信したりすることはありません。

4. Firebase Analytics（利用統計）

第三者サービス

本アプリはアプリの改善目的で Firebase Analytics（Google LLC） を使用しています。

  • 収集内容：ボタン操作・画面遷移などの匿名イベント
  • 入力テキスト・個人情報は収集しません
  • 収集されたデータはGoogleのサーバーに送信・保存されます
  • Googleのプライバシーポリシー：policies.google.com/privacy

広告SDK・クラッシュレポートSDK（サードパーティ製）・広告トラッキングは使用しません。

5. データの共有

Firebase Analytics を通じたGoogleへのデータ送信を除き、本アプリは個人データを第三者と共有しません。外部データブローカー・広告ネットワーク・分析サービスとのデータ共有は行いません。

6. データの保持と削除

端末内のすべてのデータ（設定・履歴・フレーズライブラリ）はアプリのサンドボックスに保存されます。アプリを削除するとすべてのデータが完全に削除されます。Firebase Analyticsのデータ保持期間はGoogleのポリシーに準じます。

7. 年齢制限

本アプリは12歳以上を対象としています。13歳未満の児童から意図的に個人情報を収集することはありません。

8. プライバシーポリシーの変更

本ポリシーを変更した場合、このページの「最終更新日」を更新します。重要な変更がある場合はアプリ内でもお知らせします。

摘要

本应用不会将您输入的文本发送至任何外部服务器。无需登录，不使用广告 SDK。为改善应用体验，我们使用 Firebase Analytics（Google） 收集匿名操作统计数据（如按钮点击、界面切换）。收集的内容不包含任何输入文字或个人信息。

1. 收集的信息

本应用（失礼チェック / BizKeigo）收集以下信息：

  • 仅在本机存储（不外传）： 应用设置（语言、主题、引导状态）、您创建的模板、常用短语及检查历史
  • 发送至 Firebase Analytics 的匿名数据：
    • 底部导航栏的 Tab 切换操作
    • "分析文章"、"生成模板"、"复制"、"保存"等按钮点击
    • 设置变更（语言/外观切换、数据清除确认）

上述匿名事件不包含输入文本、姓名、邮箱等任何可识别个人身份的信息。

2. 文本处理

您输入的商务日语文本默认仅在本机进行分析和评分，不会发送至外部 AI 服务、翻译 API 或任何服务器。

3. 剪贴板使用

仅当您明确执行"粘贴"或"复制"操作时，应用才会访问剪贴板。应用不会自动读取剪贴板内容，也不会将其发送至外部。

4. Firebase Analytics（使用统计）

第三方服务

本应用使用 Firebase Analytics（Google LLC） 来改善应用功能。

  • 收集内容：按钮操作、页面切换等匿名事件
  • 不收集输入文本或个人信息
  • 数据将发送并存储至 Google 服务器
  • Google 隐私政策：policies.google.com/privacy

本应用不使用广告 SDK、第三方崩溃报告 SDK 或广告追踪框架。

5. 数据共享

除通过 Firebase Analytics 向 Google 发送匿名数据外，本应用不与任何第三方共享个人数据，不向数据经纪商、广告网络或分析服务传输数据。

6. 数据保留与删除

所有本地数据（设置、历史、短语库）保存在本机应用沙盒中。卸载应用后，所有数据将被永久删除。Firebase Analytics 数据的保留期限遵循 Google 的相关政策。

7. 年龄限制

本应用面向 12 岁及以上用户。我们不会故意收集 13 岁以下儿童的个人信息。

8. 隐私政策变更

如有更新，我们将修改本页面的"最后更新日期"。如有重大变更，将在应用内进行通知。

Summary

BizKeigo does not send your input text to any external server. No login or ad SDK is used. To improve the app, we use Firebase Analytics (Google) to collect anonymous usage statistics such as button taps and screen navigation. No input text or personal information is ever collected.

1. Information We Collect

BizKeigo collects the following information:

  • Stored on-device only (never transmitted): App preferences (language, appearance, onboarding status), templates, phrase library entries, and check history you create
  • Anonymous data sent to Firebase Analytics:
    • Bottom navigation tab switches
    • Button taps: "Analyze", "Generate template", "Copy", "Save", etc.
    • Settings changes (language/appearance switches, data deletion confirmations)

These anonymous events contain no input text, names, email addresses, or any personally identifiable information.

2. Text Processing

Business Japanese text you enter is analyzed and scored on-device by default. Your text is never sent to external AI services, translation APIs, or any server.

3. Clipboard Access

The app accesses the clipboard only when you explicitly tap Paste or Copy. It does not read clipboard content automatically or transmit it anywhere.

4. Firebase Analytics (Usage Statistics)

Third-party service

BizKeigo uses Firebase Analytics (Google LLC) to improve the app experience.

  • Data collected: anonymous button-tap and screen-navigation events
  • Input text and personal information are never collected
  • Collected data is transmitted to and stored on Google's servers
  • Google Privacy Policy: policies.google.com/privacy

BizKeigo does not use ad SDKs, third-party crash reporting SDKs, or Apple's App Tracking Transparency (ATT) framework.

5. Data Sharing

Except for the anonymous event data sent to Google via Firebase Analytics, we do not share personal data with any third party, data broker, advertising network, or analytics service.

6. Data Retention and Deletion

All on-device data (preferences, history, phrase library) is stored in the app's sandbox. Deleting the app permanently removes all local data. Firebase Analytics data retention follows Google's policies.

7. Age Restriction

BizKeigo is intended for users aged 12 and older. We do not knowingly collect personal information from children under 13.

8. Changes to This Policy

If we update this policy, we will revise the "Last updated" date above. Material changes will be communicated within the app.
